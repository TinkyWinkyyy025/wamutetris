# Wamu Tetris

A browser-friendly Wamu Cafe Tetris-style game with Individual mode.

Live site: https://wamutetris.vercel.app

## Features

- Individual mode
- Responsive single-screen layout
- Canvas-based Tetris gameplay
- Ghost piece landing preview
- Hold block control
- Touch and keyboard controls

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
